# Echo Evolution Arena

You are a senior full-stack engineer, game developer, AI engineer, product designer, and hackathon technical lead.

Build a complete, polished, production-quality hackathon project called:

ECHO//LOOP

Tagline:

"THE GAME REMEMBERS HOW YOU PLAY."

The project is a browser-based AI adaptive arena game where the player's own gameplay behavior is analyzed and transformed into an AI-controlled opponent called an Echo.

The core gameplay loop is:

PLAYER PLAYS
→ GAME RECORDS BEHAVIOR
→ AI ANALYZES BEHAVIOR
→ BEHAVIORAL DNA IS CREATED
→ AI GENERATES AN ECHO STRATEGY
→ ECHO BECOMES THE PLAYER'S OPPONENT
→ PLAYER FIGHTS THEIR OWN PLAYSTYLE
→ NEW BEHAVIOR IS RECORDED
→ THE ECHO EVOLVES

The product must feel like a real game/product, NOT a demo dashboard and NOT a chatbot with a game attached.
